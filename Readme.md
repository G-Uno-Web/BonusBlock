## 五、发布注意事项（务必看）

1. **必须标明利益关系**：YouTube 和 Facebook 对推广链接有披露要求，文案里保留 "I earn a referral bonus" / "这是我的邀请链接，我有返佣" 这类说明，能显著降低被删帖、封号的风险。
2. **绝对不能出现的词**：稳赚、保本、包赚、 guaranteed profit、passive income、翻倍、躺赚。这类表述容易被平台判定为金融诈骗，也容易踩合规红线。
3. **每条都带上风险提示**：一句 "Not financial advice / 非投资建议" 成本极低，但能极大提高存活率。
4. **不要批量刷同一条**：同一段文案短时间发几十个视频/帖子，平台会判为 spam。建议 3–5 个版本轮换，并配合视频主题微调开头一句。
5. **B站特别注意**：B站对站外链接敏感，评论区链接可能被折叠或吞掉。优先发在主页简介、置顶评论，或做成"个人主页链接"形式，比评论里硬塞更稳。
6. **先小范围测试**：先发 2–3 条看留存率和点击，再决定要不要加大力度。
